## Usage policy
The binary is not committed to this repository. Acceptance CI downloads the source, records SHA-256 and media metadata, processes it, and uploads only evidence/output artifacts. A source change therefore remains observable instead of silently replacing the fixture.

## Evidence levels
- Contract tests with JSON fixtures: architecture/contract evidence only.
- This public-domain human video: real-media pipeline acceptance evidence.
- A user-owned production clip: later product/customer acceptance evidence.

Do not describe synthetic video or generated motion samples as satisfying this real-media gate.
